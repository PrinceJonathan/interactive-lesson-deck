# 各科目：概念 → 互動圖解對照

挑概念的檢查問題：**學生拖／點／調一個東西之後，畫面的變化能不能直接顯示規則？** 能就適合圖解；只是要背的清單就不適合（改放講解面板的表格）。

每一列都寫成「學生操作 X → 畫面與答案怎麼變」。

## 英文（本次實作過）
| 概念 | 圖解 | 操作 → 變化 |
|---|---|---|
| 時態 | 過去／現在／未來時間軸 + 點／線／箭頭 | 拖動時間詞或長條 → 動詞形態改變 |
| 頻率副詞 | 一週七格 + 滑桿 | 拉滑桿 → 亮起天數、百分比、副詞同步變 |
| since / for | 年份軸 + 可拖起點 | 拖起點 → since 年份與 for 年數同步換算 |
| been / gone to | 兩地地圖 + 人物動畫 | 按播放，暫停問「現在人在哪？」 |
| 被動語態（未做） | 主詞、動詞、受詞三個可拖字塊 | 拖字塊到新位置 → 自動變 be + p.p. + by |
| 比較級／最高級（未做） | 2～3 個角色的長條 | 調數值 → -er／more／the -est 切換，含不規則變化 |
| 數量詞（未做） | 冰箱／籃子 + 數量滑桿 | 放入可數／不可數物品、拉數量 → many／much／a few／a little |
| 從屬連接詞（未做） | 兩張子句卡片 + 關係圖 | 換連接詞 → 時間／條件／讓步／因果關係圖改變，句首自動加逗號 |

## 數學
| 概念 | 圖解 | 操作 → 變化 |
|---|---|---|
| 一次函數 y = ax + b | 座標平面 | 拉 a、b 滑桿 → 直線斜率、截距變，點的座標表同步 |
| 二次函數 | 拋物線 | 拉 a、h、k → 開口、頂點、對稱軸變 |
| 三角形內角和／全等 | 可拖頂點的三角形 | 拖頂點 → 三個角度變、總和固定 180° |
| 比例／百分率 | 長條或圓餅 | 拉數值 → 面積與百分比同步 |
| 機率 | 骰子／抽球實驗 | 重複實驗 → 長條圖逼近理論值 |

## 理化／自然
| 概念 | 圖解 | 操作 → 變化 |
|---|---|---|
| 等速／加速運動 | 位置 - 時間圖 + 小車 | 拖時間軸 → 小車位置、速度、圖線同步 |
| 電路 | 電池 + 燈泡 + 開關 | 切開關、調電阻 → 燈亮度、電流變 |
| 浮力 | 水槽 + 物體 | 調物體密度 → 浮／沉、受力箭頭變 |
| 酸鹼 | pH 尺 | 拖指示劑位置 → 顏色與酸鹼性變 |
| 光的折射 | 兩介質 + 光線 | 拖入射角 → 折射角即時算出 |

## 社會（歷史／地理）
| 概念 | 圖解 | 操作 → 變化 |
|---|---|---|
| 歷史事件順序 | 時間軸 | 拖事件卡到正確年代 → 對了吸附、錯了彈回 |
| 朝代／版圖 | 地圖 + 年份滑桿 | 拉年份 → 版圖範圍變化 |
| 地形與氣候 | 剖面圖 | 拉緯度或海拔 → 氣溫、降雨、植被變 |
| 人口結構 | 人口金字塔 | 拉年份 → 金字塔形狀與扶養比變 |

## 國文
| 概念 | 圖解 | 操作 → 變化 |
|---|---|---|
| 句型／修辭 | 句子拆解圖 | 點字詞 → 標示詞性／修辭種類 |
| 文章結構 | 段落卡片 | 拖段落排出起承轉合 |
| 詞語演變 | 時間軸 | 拖時間 → 字形或用法變 |

## 沒有適合圖解的內容
單字表、年代表、公式清單：做成講解面板的表格（`<table>`），不要硬做互動。

## 一個主題要拆成幾頁？
一頁只講一件事。如果概念頁的句子裡要同時指出兩件事（例如「時態」和「主詞變化」），拆成兩個主題；或把第二件事放進練習頁的講解。

# interactive-lesson-deck

把教材做成「老師上課投影用」的互動教學簡報網站，以及可重複使用的 Claude Skill。

- **一頁一重點**：每個主題分成「概念頁」和「練習頁」。
- **圖解放中間、題目在圖下面**：學生拖、點、調整，畫面與答案跟著變。
- **老師工具**：雷射筆、5 色畫筆、橡皮擦、垃圾桶、目錄、講解面板、暫停／重設／放大。
- **單一 HTML 檔**，雙擊就能開，適合 1920×1080 投影。

## 內容

| 路徑 | 說明 |
|---|---|
| `tense-preview.html` | 成品範例：高職英文「時態系列」11 個主題、22 頁 |
| `.claude/skills/interactive-lesson-deck/` | Claude Skill：流程、設計原則、骨架樣板、各科圖解對照 |

## 使用成品範例

直接用瀏覽器開啟 `tense-preview.html`。

| 按鍵 | 功能 |
|---|---|
| ← → | 上一頁／下一頁 |
| 1–9、0 | 跳到主題 1–9、10 |
| M | 目錄 |
| H | 講解 |
| Q | 換一題 |
| Enter | 對答案 |
| P / R / F | 播放暫停／重設／放大圖解 |
| L / D / E / C | 雷射筆／畫筆／橡皮擦／清除本頁筆跡 |

## 使用 Skill 做其他科目

把 `.claude/skills/interactive-lesson-deck/` 放進專案的 `.claude/skills/`（或個人的 `~/.claude/skills/`），
然後告訴 Claude Code：「請把這份教材做成互動教學簡報網站」並附上教材檔案。
流程會先問對象與範圍、讀教材、提出逐頁規劃，確認後再做預覽。

- 本專案的程式碼與 Skill 可自由使用。
- 範例中的英文例句與練習題取自出版社教材，僅作為教學展示範例；**原書 PDF 不包含在此儲存庫**。
  若要用於自己的課程，請改用你有權使用的教材內容。
